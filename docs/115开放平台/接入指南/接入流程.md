# 接入流程

## 1. 注册“115生活”账号

在使用 115 开放平台服务前，开发者需要先通过 [“115生活”官网](https://115.com/) 注册并登录账号，完成实名认证。

## 2. 提交入驻申请

访问 [115 生活开放平台](https://open.115.com/)，按页面流程填写申请资料。

### 2.1 选择开发者身份类型

开发者可以选择认证为“个人开发者”或“企业开发者”。页面上方支持切换申请类型。

![开发者身份类型](./img/oDN7EX8WqAUUp8oi/1747751145122-e7821703-ddef-4b70-97b0-72e63554299b-772505.jpeg)

### 2.2 签署协议

阅读并确认相关协议内容，无异议后勾选“同意”，点击“下一步”。

### 2.3 填写入驻资料

按页面要求填写个人信息、API 对接需求、应用场景等资料，然后点击“下一步”。

### 2.4 填写认证信息

根据开发者类型上传认证资料：

- 个人开发者：姓名、身份证信息、证件照片等。
- 企业开发者：企业负责人或法人的姓名、联系方式、身份证信息、营业执照影印件、统一社会信用代码等。

### 2.5 提交申请

确认资料无误后点击“提交验证”。平台通常会在 7 个工作日内完成审核。

## 3. 创建应用

入驻申请通过后，可以在开放平台管理页进入“应用管理”，点击“创建应用”，按要求填写应用信息、应用域名、应用描述与接口信息等内容。

应用审核通过后，开发者可获取 App ID、App Key、App Secret 等接入凭证，请妥善保存。

## 4. 接口调试

按开放平台文档完成接入后即可开始调用接口。

基础域名：

- [https://proapi.115.com/](https://proapi.115.com/)
