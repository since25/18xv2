# 开发须知

## 一、注意事项

为共同维护开放合作生态，保障平台服务的可持续发展，开发者在接入平台前应认真阅读并遵循《115生活开放平台开发者协议》的相关要求，确保合规运营。

平台会持续监测开发者的服务使用行为。如发现违反平台规范的情况，平台可能根据情节采取包括但不限于服务限流、接口冻结、资质回收等限制措施，并保留进一步追责的权利。

以下行为属于重点禁止范围：

1. 数据隐私违规行为：未经用户授权或未明确用途，违规收集、下载、存储、传播、加工用户云存储数据等。开发者需要确保用户数据的获取与使用过程透明、可追溯。
2. 商业利益侵犯行为：损害 115 科技商业利益，包括但不限于多人共享开发者账号及会员权益、开展竞争关系业务、未经授权获取平台运营数据等。
3. 不当使用行为：违规或未按要求使用 API 接口服务，包括但不限于违反国家政策法规、侵犯第三方合法权益、调用非公开接口、实际用途与申请信息不符等。

## 二、限流说明

为保障系统安全与服务稳定运行，115 生活开放平台会对所有 API 接口实施频控限制策略。出于安全防护考虑，具体策略细则不公开，且会持续动态调整。
