# 概述

## 一、“115生活”简介

“115生活”是一款面向个人用户的数字生活平台，提供海量数据的安全存储、多端同步与快速访问。用户可以便捷地管理和使用各类数字资源，同时享受多维社交与生活服务等能力。

## 二、115 生活开放平台能力说明

115 生活开放平台对外提供围绕云存储数据的标准化 API 服务，开发者可以通过接入这些接口，把 115 的存储、同步与管理能力集成到自己的应用中。

目前已开放的能力包括：

- 用户管理能力：用户授权与用户信息查询等。
- 文件管理能力：获取文件列表、查看文件详情、上传、下载、搜索、移动、删除等。
- 视频管理能力：视频文件的在线转码与播放等。
- 云下载服务：获取云下载任务列表、配额信息，以及任务添加、删除等。
- 商业价值转化：提供“推广产品得收益”计划，开发者可基于用户实际购买的产品获得相应推广收益。
