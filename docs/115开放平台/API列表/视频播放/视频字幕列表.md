# 视频字幕列表

## 基本信息

- Path：`GET 域名 + /open/video/subtitle`
- Method：`GET`
- 接口描述：获取视频字幕列表。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Query**

| 参数名称 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- |
| `pick_code` | 是 | `b53gu6z3hvqji8wrm` | 视频文件提取码 |
