# 获取视频在线播放地址

## 基本信息

- Path：`GET 域名 + /open/video/play`
- Method：`GET`
- 接口描述：获取视频播放地址及视频文件相关数据。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Body(form-data)**

| 参数名称 | 参数类型 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| `pick_code` | string | 是 | `b53gu6z3hvqji8wrm` | 文件提取码 |

## 注意事项

- 如需切换音轨，可在返回的播放地址后追加 `audio_track=<index>` 参数。
- `audio_track` 的值取自 `multitrack_list` 的下标，`value` 为音轨名称，下标从 `0` 开始。

示例：

```text
...&audio_track=0
```

## 返回数据

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `state` | bool | 操作结果状态值，`true` 成功，`false` 失败 |
| `message` | string | 异常信息，成功时为空 |
| `code` | int | 异常码，成功时返回 `0` |
| `data` | object | 数据主体 |
| `data.file_id` | string | 文件 ID |
| `data.parent_id` | string | 文件父目录 ID |
| `data.file_name` | string | 文件名称 |
| `data.file_size` | string | 文件大小 |
| `data.file_sha1` | string | 文件哈希值 |
| `data.file_type` | string | 文件类型 |
| `data.is_private` | string | 文件是否加密隐藏；`0` 否，`1` 是 |
| `data.play_long` | string | 视频文件时长 |
| `data.user_def` | int | 用户记忆的清晰度；`1` 标清，`2` 高清，`3` 超清，`4` 1080P，`5` 4K，`100` 原画 |
| `data.user_rotate` | int | 记忆视频旋转角度；`0`、`90`、`180`、`270` |
| `data.user_turn` | int | 视频翻转方向；`0` 不翻转，`1` 水平翻转，`2` 垂直翻转 |
| `data.multitrack_list` | array | 视频多音轨列表 |
| `data.multitrack_list[].title` | string | 音轨标题 |
| `data.multitrack_list[].is_selected` | string | 音轨是否上次选中；`1` 表示选中 |
| `data.definition_list_new` | array | 视频可切换清晰度列表；`1` 标清，`2` 高清，`3` 超清，`4` 1080P，`5` 4K，`100` 原画 |
| `data.video_url` | array | 各清晰度播放地址信息 |
| `data.video_url[].url` | string | 播放地址 |
| `data.video_url[].height` | int | 视频高度 |
| `data.video_url[].width` | int | 视频宽度 |
| `data.video_url[].definition` | int | 视频清晰度 |
| `data.video_url[].title` | int | 视频清晰度名称 |
| `data.video_url[].definition_n` | int | 视频清晰度（新） |
