# 记忆视频播放进度

## 基本信息

- Path：`POST 域名 + /open/video/history`
- Method：`POST`
- 接口描述：记录视频播放进度。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Body(form-data)**

| 参数名称 | 参数类型 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| `pick_code` | string | 是 | `b53gu6z3hvqji8wrm` | 文件提取码 |
| `time` | int | 否 | `10` | 视频播放进度时长，单位秒 |
| `watch_end` | int | 否 | `0` | 视频是否播放完毕；默认 `0`，`1` 表示播放完毕 |

## 注意事项

- 当 `time` 和 `watch_end` 都不传时，默认都为 `0`，即视频没有播放完毕且播放进度为 `0`。

返回结果示例：

```json
{
  "state": true,
  "message": "",
  "code": "",
  "data": {}
}
```

## 返回数据

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `state` | bool | 操作结果状态值，`true` 成功，`false` 失败 |
| `message` | string | 操作返回消息，成功时为空 |
| `code` | int | 操作返回号码，成功时返回 `0` |
| `data` | array | 数据 |
