# 获取上传凭证

## 基本信息

- Path：`GET 域名 + /open/upload/get_token`
- Method：`GET`
- 接口描述：获取上传凭证。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

## 返回数据

| 字段 | 类型 | 备注 | 其他信息 |
| --- | --- | --- | --- |
| `state` | boolean | 状态；`true` 正常，`false` 错误 |  |
| `message` | string | 异常信息 |  |
| `code` | number | 异常码 |  |
| `data` | object |  |  |
| `data.endpoint` | string | 上传域名 |  |
| `data.AccessKeySecrett` | string | 上传凭证密钥 |  |
| `data.SecurityToken` | string | 上传凭证 token |  |
| `data.Expiration` | string | 上传凭证过期时间 |  |
| `data.AccessKeyId` | string | 上传凭证 ID |  |
