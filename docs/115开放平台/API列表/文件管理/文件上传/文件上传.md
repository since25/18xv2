# 文件上传

## 基本信息

- Path：`POST 域名 + /open/upload/init`
- Method：`POST`
- 接口描述：断点续传上传初始化调度接口。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Body(form-data)**

| 参数名称 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- |
| `file_name` | 是 | `图片.jpg` | 文件名 |
| `file_size` | 是 | `5335` | 文件大小（字节） |
| `target` | 是 | `U_1_0` | 文件上传目标约定；`U_1_` 为固定前缀，`0` 表示根目录，其余数字表示文件夹 ID |
| `fileid` | 是 |  | 文件 SHA1 值 |
| `preid` | 否 |  | 文件前 128K 的 SHA1 |
| `pick_code` | 否 |  | 上传任务 key（非秒传调度接口返回的 `pick_code` 字段） |
| `topupload` | 否 | `0` | 上传调度标记：`0` 单文件上传；`1` 文件夹任务的第一个子文件；`2` 文件夹任务的后续子文件；`-1` 表示无该参数 |
| `sign_key` | 否 |  | 二次认证需要 |
| `sign_val` | 否 |  | 二次认证需要，且需为大写 |

## 返回数据

| 字段 | 类型 | 备注 | 其他信息 |
| --- | --- | --- | --- |
| `state` | boolean | 状态；`true` 正常，`false` 错误 |  |
| `message` | string | 异常信息 |  |
| `code` | number | 异常码 |  |
| `data` | object |  |  |
| `data.pick_code` | string | 上传任务唯一 ID，用于续传 |  |
| `data.status` | number | 上传状态；`1` 非秒传，`2` 秒传 |  |
| `data.sign_key` | string | 本次计算的 SHA1 标识（二次认证） | 参照下方“二次认证”说明 |
| `data.sign_check` | string | 本次计算的本地文件 SHA1 区间（二次认证） | 参照下方“二次认证”说明 |
| `data.file_id` | string | 秒传成功后新增的文件 ID |  |
| `data.target` | string | 文件上传目标约定 |  |
| `data.bucket` | string | 上传 bucket |  |
| `data.object` | string | OSS object ID |  |
| `data.callback` | string | 上传完成回调信息 |  |
| `data.callback_var` | string | 上传完成回调参数 |  |

## 二次认证

| code | status | 说明 | 后续处理 | 第二次验证 |
| --- | --- | --- | --- | --- |
| `700` | `6` | 签名认证后失败 | 根据 `sign_check` 指定的字节区间重新计算 SHA1，例如 `"2392148-2392298"` 表示对该闭区间内容计算 SHA1 | 传回 `sign_key` 与 `sign_val`（大写 SHA1） |
| `701` | `7` | 需要认证签名 |  |  |
| `702` | `8` | 签名认证失败 |  |  |
