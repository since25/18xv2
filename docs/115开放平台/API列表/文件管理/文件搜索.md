# 文件搜索

## 基本信息

- Path：`GET 域名 + /open/ufile/search`
- Method：`GET`
- 接口描述：根据文件名搜索文件（夹）。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Query**

| 参数名称 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- |
| `search_value` | 是 |  | 查找关键字 |
| `limit` | 是 |  | 单页记录数，默认 `20`，且 `offset + limit` 最大不超过 `10000` |
| `offset` | 是 |  | 数据显示偏移量 |
| `file_label` | 否 |  | 支持文件标签搜索 |
| `cid` | 否 |  | 目标目录；当 `cid=-1` 时，表示不返回列表内容 |
| `gte_day` | 否 |  | 搜索结果匹配的开始时间，格式：`2020-11-19` |
| `lte_day` | 否 |  | 搜索结果匹配的结束时间，格式：`2020-11-20` |
| `fc` | 否 |  | 只显示文件或文件夹；`1` 只显示文件夹，`2` 只显示文件 |
| `type` | 否 |  | 一级筛选大类；`1` 文档，`2` 图片，`3` 音乐，`4` 视频，`5` 压缩包，`6` 应用 |
| `suffix` | 否 |  | 一级筛选选择“其他”时填写的后缀名 |

## 返回数据

| 字段 | 类型 | 备注 | 其他信息 |
| --- | --- | --- | --- |
| `count` | number | 搜索符合条件的文件（夹）总数 |  |
| `data` | object[] |  | item 类型：object |
| `data[].file_id` | string | 文件 ID |  |
| `data[].user_id` | string | 用户 ID |  |
| `data[].sha1` | string | 文件 SHA1 值 |  |
| `data[].file_name` | string | 文件名称 |  |
| `data[].file_size` | string | 文件大小 |  |
| `data[].user_ptime` | string | 上传时间 |  |
| `data[].user_utime` | string | 更新时间 |  |
| `data[].pick_code` | string | 文件提取码 |  |
| `data[].parent_id` | string | 父目录 ID |  |
| `data[].area_id` | string | 文件状态；`1` 正常，`7` 删除（回收站），`120` 彻底删除 |  |
| `data[].is_private` | number | 文件是否隐藏；`0` 未隐藏，`1` 已隐藏 |  |
| `data[].file_category` | string | `1` 文件，`0` 文件夹 |  |
| `data[].ico` | string | 文件后缀 |  |
| `limit` | number | 分页值 |  |
| `offset` | number | 偏移值 |  |
| `state` | boolean | 状态；`true` 正常，`false` 错误 |  |
| `message` | string | 异常信息 |  |
| `code` | number | 异常码 |  |
