# 回收站列表

## 基本信息

- Path：`GET 域名 + /open/rb/list`
- Method：`GET`
- 接口描述：获取回收站列表。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Query**

| 参数名称 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- |
| `limit` | 是 | `30` | 单页记录数，默认 `30`，最大 `200` |
| `offset` | 是 | `0` | 数据显示偏移量 |

## 返回数据

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| `state` | boolean |  |
| `message` | string |  |
| `code` | number |  |
| `data` | object |  |
| `data.offset` | number | 偏移量 |
| `data.limit` | number | 分页量 |
| `data.count` | string | 回收站文件总数 |
| `data.rb_pass` | number | 是否设置回收站密码 |
| `data.<recycle_id>` | object | 文件（夹）回收站 ID 对应的数据 |
| `data.<recycle_id>.id` | string | 文件（夹）回收站 ID |
| `data.<recycle_id>.file_name` | string | 文件（夹）名称 |
| `data.<recycle_id>.type` | string | 类型；`1` 文件，`2` 目录 |
| `data.<recycle_id>.file_size` | string | 文件大小 |
| `data.<recycle_id>.dtime` | string | 删除日期 |
| `data.<recycle_id>.thumb_url` | string | 缩略图地址 |
| `data.<recycle_id>.status` | string | 还原状态；`-1` 表示还原中，`0` 表示正常状态 |
| `data.<recycle_id>.cid` | number | 原文件父目录 ID |
| `data.<recycle_id>.parent_name` | string | 原文件父目录名称 |
| `data.<recycle_id>.pick_code` | string | 文件提取码 |
