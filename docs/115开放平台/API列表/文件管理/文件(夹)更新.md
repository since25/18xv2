# 文件(夹)更新

## 基本信息

- Path：`POST 域名 + /open/ufile/update`
- Method：`POST`
- 接口描述：更新文件名或星标状态。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Body(form-data)**

| 参数名称 | 参数类型 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| `file_id` | text | 是 | `3073323042143855813` | 需要更新的文件（夹）ID |
| `file_name` | text | 否 | `新的名字` | 新的文件（夹）名称；文件夹名称限制 255 字节 |
| `star` | text | 否 | `1` | 是否星标；`1` 星标，`0` 取消星标 |

## 返回数据

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| `state` | boolean | 状态；`true` 正常，`false` 异常 |
| `message` | string | 异常信息 |
| `code` | number | 异常码 |
| `data` | object |  |
| `data.file_name` | string | 新的文件（夹）名称 |
| `data.star` | string | 文件星标状态 |
