# 获取用户云下载任务列表

## 基本信息

- Path：`GET 域名 + /open/offline/get_task_list`
- Method：`GET`
- 接口描述：获取用户云下载任务列表。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

**Query**

| 参数名称 | 是否必须 | 示例 | 备注 |
| --- | --- | --- | --- |
| `page` | 否 | `1` | 获取列表页码，不传默认为第一页 |

## 注意事项

- 无。

## 返回数据

| 字段 | 类型 | 备注 | 其他信息 |
| --- | --- | --- | --- |
| `state` | boolean |  |  |
| `message` | string |  |  |
| `code` | number |  |  |
| `data` | array |  |  |
| `data.page` | int | 当前页码 |  |
| `data.page_count` | int | 总页数 |  |
| `data.count` | int | 总数量 |  |
| `data.tasks` | array | 云下载任务列表 |  |
| `data.tasks[].info_hash` | string | 任务 SHA1 |  |
| `data.tasks[].add_time` | int | 任务添加时间戳 |  |
| `data.tasks[].percentDone` | int | 任务下载进度 |  |
| `data.tasks[].size` | int | 任务总大小（字节） |  |
| `data.tasks[].name` | string | 任务名 |  |
| `data.tasks[].last_update` | int | 任务最后更新时间戳 |  |
| `data.tasks[].file_id` | string | 任务源文件（夹）对应的文件（夹）ID |  |
| `data.tasks[].delete_file_id` | string | 删除任务且需要删除源文件（夹）时需传递的文件（夹）ID |  |
| `data.tasks[].status` | int | 任务状态：`-1` 下载失败，`0` 分配中，`1` 下载中，`2` 下载成功 |  |
| `data.tasks[].url` | string | 链接任务 URL |  |
| `data.tasks[].wp_path_id` | string | 任务源文件所在父文件夹 ID |  |
| `data.tasks[].def2` | int | 视频清晰度；`1` 标清，`2` 高清，`3` 超清，`4` 1080P，`5` 4K，`100` 原画 |  |
| `data.tasks[].play_long` | int | 视频时长 |  |
| `data.tasks[].can_appeal` | int | 是否可申诉 |  |
