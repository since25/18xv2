# 用户信息

API：

- `GET 域名 + /open/user/info`

说明：

- 获取用户空间和 VIP 信息。

## 请求参数

**Headers**

| 参数名称 | 参数值 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| `Authorization` | `Bearer access_token` | 是 | `Bearer abcdefghijklmnopqrstuvwxyz` |

## 返回数据

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `state` | boolean | 接口状态，`true` 正常，`false` 异常 |
| `message` | string | 异常信息 |
| `code` | string | 异常码 |
| `data` | object | 数据主体 |
| `data.user_id` | string | 用户 ID |
| `data.user_name` | string | 用户名称 |
| `data.user_face_s` | string | 小尺寸用户头像 |
| `data.user_face_m` | string | 中尺寸用户头像 |
| `data.user_face_l` | string | 大尺寸用户头像 |
| `data.rt_space_info` | object | 用户空间信息 |
| `data.all_total` | object | 用户总空间 |
| `data.all_total.size` | int | 用户总空间大小（字节） |
| `data.all_total.size_format` | string | 用户总空间大小（格式化） |
| `data.all_remain` | object | 用户剩余空间 |
| `data.all_remain.size` | int | 用户剩余空间大小（字节） |
| `data.all_remain.size_format` | string | 用户剩余空间大小（格式化） |
| `data.all_use` | object | 用户已使用空间 |
| `data.all_use.size` | int | 用户已使用空间大小（字节） |
| `data.all_use.size_format` | string | 用户已使用空间大小（格式化） |
| `data.vip_info` | object | 用户 VIP 等级信息 |
| `data.vip_info.level_name` | string | VIP 等级名称 |
| `data.vip_info.expire` | int | 过期时间戳 |
