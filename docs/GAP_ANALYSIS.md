## 四、当前主要风险

### 风险 1：服务器侧部署操作过猛时，Docker 子进程可能堆积

现象：

- 连续执行大量 `compose/build/exec/cp/logs` 操作时，宿主机曾出现 Docker 进程堆积。

建议：

- 部署保持串行。
- 优先用一次 `rsync` + 一次 `docker compose up -d --build`。
- 非必要不要在容器频繁 `docker cp` 热修。

### 风险 2：历史任务的远端路径可能已经失效

现象：

- 部分旧任务执行时 `blocked`，原因并非 token，而是远端目录结构已变化。

建议：

- 短期先把错误提示做明确。
- 中期再决定是否引入重新解析或重定向策略。

### 风险 3：如果后续重新引入路径级关键词匹配，容易回到旧性能陷阱

现象：

- 旧逻辑对 `raw_path` 做 contains，导致祖先目录在大量子节点上重复命中。

建议：

- 当前只保留节点名匹配。
- 如果必须恢复路径语义，需要单独设计约束和测试，不能直接回滚旧实现。
